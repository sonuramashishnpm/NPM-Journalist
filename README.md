# NPM Journalist

**Raise your voice safely — Send complaints or suggestions to government officers anonymously.**

NPM Journalist is a web platform that allows citizens to send complaints or messages to government officers (DMs, CMs, SPs, etc.) without revealing any personal information. 

An AI safety layer reviews every message before sending to ensure it is respectful, non-offensive, and free from threats.

## ✨ Features

- Completely anonymous - no login, no email, no phone required
- AI safety check before sending message
- Blocks offensive words and threats
- Sends email only if AI says "Yes"
- Modern UI with background video
- Supports officers like DM Kota, Rajasthan CM, Bihar CM, SPs etc.
- Mobile friendly

## 📖 How It Works

1. User selects officer, writes subject and complaint
2. Clicks Send button
3. AI (qwen2.5-coder:7b) reviews the message
4. If safe → email is sent using Gmail API
5. If not safe → user gets rejection message
